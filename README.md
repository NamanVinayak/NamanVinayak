### Naman Vinayak

I design AI agent workflows and ship production software with them. I own the architecture,
the specs and the agent pipeline, then build, test and debug until it holds up with real
users. My point-of-sale system has run a retail store's daily sales since October 2026.
I come from film, so a lot of my work sits where software meets video. Vancouver, BC.

**What I've built**
- **A point-of-sale system running a home-furnishings store in BC** (private client work,
  live since October 2026): sales, deliveries, returns and exchanges, store credit, a
  Shopify website link, backups and daily email reports.
- **The same store's new website** ([instylehomefurnishings.ca](https://www.instylehomefurnishings.ca)):
  a custom Shopify storefront built from scratch with 24 custom sections, including
  scroll-scrubbed hero and furniture-assembly films, shoppable room scenes with hotspots, and
  a showroom tour. The films and imagery were made with generative AI video and image models.
- **[Postgame](https://github.com/NamanVinayak/postgame)**: free Chess.com game review with
  Stockfish running in the browser (React + TypeScript, 170 tests, CI). Next up is
  [Postgame Coach](https://github.com/NamanVinayak/postgame/blob/main/ROADMAP.md), an AI
  chess coach that pairs an LLM with Stockfish over MCP.
- **[EditorialCut](https://github.com/NamanVinayak/EditorialCut)**: an editing system for
  AI coding agents, with 16 skills, a written editing rulebook and tested capability docs
  on top of Remotion, HyperFrames and FFmpeg.
- **[viral-clip-extractor](https://github.com/NamanVinayak/viral-clip-extractor)**: long
  videos into captioned 9:16 shorts (Hindi included), with two-stage LLM clip selection.
- **[ai-multi-agent-storyboarder](https://github.com/NamanVinayak/ai-multi-agent-storyboarder)**:
  script to storyboard with a crew of agents (producer, director, DOP, prompt engineer),
  image generation, and DaVinci Resolve XML export. Unfinished, shared for forking.
- **[hand-tracking-pipeline](https://github.com/NamanVinayak/hand-tracking-pipeline)**:
  egocentric hand tracking for robotics data, MediaPipe locally and HaMeR on serverless GPU.
- **[Is That Real?](https://apps.apple.com/ca/app/is-that-real/id6767705562)**: an iOS
  fact-checking app on the App Store (SwiftUI, Cloudflare Workers, subscriptions).

**How I work:** spec first, then a step-by-step plan, then agents build against it while I
review, test and debug every change. Postgame's `docs/` shows the spec and plan it was
built from.
